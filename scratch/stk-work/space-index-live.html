Viewer · macOS · Windows · Linux

SkinTokens

The viewer shows the meshes, materials, textures and animations in a 3D character file. It opens .glb, .gltf and .vrm files. Press R to rig a .glb file on your GPU. The viewer saves the result as <name>.rigged.glb in the folder of your file, and shows that path. Each file contains the program, skintokens-viewer.pck, the godot-sandbox file and the weights in the folder w. The program does not connect to other computers. Keep the files in one folder.

Open a model

Drag and drop a file, or type its path

Drag and drop

Drag and drop a .glb, .gltf or .vrm file on the window. The viewer replaces the model on the screen with the new file.

From a terminal

Type the file path after the program name.

skintokens-viewer /path/to/model.vrm

Information

The left panel shows all the meshes, materials, textures and animations in the file. Double-click a texture to see a large view of it.

Keys

Press W to show the wireframe. Press E to explode the model at its joints. Press G to remove the grid from the view.

Controls

The controls card shows all the controls

The viewer shows the controls card in the bottom-right corner when it starts. Press H to close the card. Press H again to show it.

Status

The viewer and the auto-rig are available on the desktop

  • The desktop viewers rig a .glb file when you press R. On an Apple M2 Pro (Metal), the macOS viewer gave three test characters the same rig as the SkinTokens rig program. On an NVIDIA RTX 4090 (Vulkan), the Windows viewer gave one test character the same joints, and its joint weights are different by 0.000001 or less. There is no test result for the auto-rig in the Linux viewer.
  • At this time, the viewer does not open .usdz files.
  • The macOS version opened four test characters with their textures. The test used three VRM files and one GLB file.
  • The Linux version opened the same four files on Fedora 44 in WSL. This test used no window.
  • The Windows file on this page opened the same four files on Windows 11. This test used no window.
  • At this time, the Linux and Windows versions have no test with a window.
